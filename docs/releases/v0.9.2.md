# v0.9.2

- Add the `tokenize` JSON-RPC method to `numr-cli --server`: syntax tokens for one line with the server's variables promoted, so clients without the WASM tokenizer (the Omarchy overlay) can highlight like the TUI and the web.
- `numr-editor` gains a `serde` feature for the token types; `wasm` enables it.
- TUI: `Ctrl+n` clears the document (#16). The file on disk is untouched until the next save.
