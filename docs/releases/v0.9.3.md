# v0.9.3

- Optional fallback fiat-rate source: `[api] fiat_rates_fallback_url` in `config.toml`, contacted only when the primary source fails and unset by default (#21, by @cahthuranag).
- `numr-cli` and the JSON-RPC server now read the `[api]` section of `config.toml` (rate URLs, fallback, CoinGecko key) like the TUI does, so the same endpoints serve every frontend built on them.
